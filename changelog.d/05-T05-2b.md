- **Verifier kernel: native TRX amount bound.** The strict TRON decoder now refuses a native TRX transfer of more than 2^53 − 1 sun (about 9.0 billion TRX), JavaScript's largest safe integer (`Number.MAX_SAFE_INTEGER`), so the kernel and JS tooling such as tronweb always read the same amount. TRC-20 amounts are not affected. The refusal has its own name and uses the existing `TX_VALUE_NOT_ALLOWED` wire code. The tronweb differential no longer sets aside native amounts that tronweb rounds; it compares every accepted amount exactly. The INTENT_V1 draft documents the bound; its vector file is regenerated once the independent oracle implements the check.
