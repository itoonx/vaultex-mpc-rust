- CI: new `Claims` workflow with a `Claims-lint` job (ROADMAP M5 #10). It runs on every push, on pull requests to `main` and daily, so claims that expire are caught. It fails if a claim breaks `claims/schema.toml` or the ledger rules (`claims/claims.py check`), if `CLAIMS.md` is not byte-identical to a fresh render of `claims/**`, or if a file under `claims/` sits where the renderer never reads it.
- `scripts/ci/claims_lint.sh` runs the same checks locally without writing the working tree, and `scripts/ci/test_claims_lint.py` proves that each failure class turns the job red.
