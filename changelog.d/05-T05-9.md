- **Verifier kernel: incident replay and tronweb differential (evidence, part 1).** `vaultex-verify` now replays the red-team incident catalogue through its strict TRON decoder: every case whose fault is in the transaction bytes is refused with an expected code, and every control is accepted. The cases that only the policy, approval and request checks can catch stay listed as pending until those layers exist. A differential harness decodes 12,000 deterministic mutants of the reference transactions with the kernel and with tronweb (pinned to the version `scripts/` uses), and compares every kernel acceptance field by field. It found one open class: native amounts above 2^53 − 1 sun, which tronweb rounds to a JS number. The class is reported separately until a decision is made on it.
