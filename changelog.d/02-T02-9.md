- Toolchain: the workspace now declares its minimum supported Rust version, `rust-version = "1.93"` in `[workspace.package]`. That is the one toolchain the code is verified on (1.93.1). Locked dependencies already need at least 1.91, and a lower MSRV will only be claimed once a CI job builds on it. Member crates do not inherit the field until they opt in.
- CI: new `.github/dependabot.yml` for weekly Cargo and GitHub Actions version updates against `dev`. Minor and patch Cargo bumps arrive as one batched PR, majors one PR each, and all Actions bumps as one PR, with SHA pins and their version comments updated together. New releases must age (7 days, 30 for Cargo majors) before they are proposed, and the exact-pinned `glass_pumpkin` is excluded. Every update PR is a proposal that still needs green CI and review.
