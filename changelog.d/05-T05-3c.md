- **Verifier kernel: quorum policy bundles anchor to the last quorum bundle (ADR-11, 2026-10-18).** A policy bundle's version is now a pair `(epoch, seq)`. A quorum bundle (`seq` 0) always needs M-of-N admin signatures, starts a new epoch and names as its parent the quorum bundle that started the epoch in force. A one-admin tightening is a step within the epoch (`seq` above the current one) that names the bundle in force. Steps can no longer move the epoch, the parent a quorum bundle needs, or the time lock, so a quorum-signed change such as an admin rotation stays installable and is not delayed however many single-admin tightenings are installed after it was signed. It is still classified against the bundle in force, so a change that drops those tightenings waits out its time lock. Steps are refused while a loosening is pending, versions cannot jump to the end of their range, and the anchor is kept in the installed file across restarts. Requests and receipts keep a single number for the version (`epoch · 2^32 + seq`). The bundle body changed shape, which is allowed while the `POLICY_BUNDLE_V1` RFC is a draft; the vector file is regenerated (regression vectors from the kernel's own encoder; the independent oracle has not reproduced them yet).
