- docs: new claims ledger. `claims/schema.toml` defines one TOML file per public claim (status, pinned evidence, expiry); `claims/01/` holds 36 live claims covering every claim-bearing line of `README.md` and `README.zh-CN.md`, plus 12 withdrawn records for retracted statements; `CLAIMS.md` is generated from them.
- tooling: `claims/claims.py` (Python standard library only) renders `CLAIMS.md` deterministically, and `check` fails on schema errors, unpinned or missing evidence, expired claims, README lines that no claim covers, and hand edits to `CLAIMS.md`.
