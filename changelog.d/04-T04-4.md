- **Chain gating (M5).** `mpc-wallet export-address` and `GET /v1/chains/{chain}/address/{id}` now serve an address only for a chain whose address derivation was verified end to end (Ethereum, Bitcoin testnet, Solana, Sui, Aptos, TRON) and a wallet scheme whose signatures can spend from it; every other chain/scheme pair, including all 44 unverified chains, gets a refusal instead of an address, and FROST-Secp256k1-TR wallets never get a P2WPKH (or any Bitcoin) address. The address endpoint also refuses on a gateway configured for a non-test network.
