- **Release freeze (M5 #5).** `mpc-node` and the API gateway now refuse key generation, raw-digest signing, every legacy signing scheme and any network other than testnet/devnet. Every build is frozen by default; the debug-only `dev-unfreeze` feature lifts it for testnet development, and a release build with that feature does not compile. Each refusal has a named `freeze_refuses_*` test.
