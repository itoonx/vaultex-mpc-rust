- **Release freeze (M5 #5).** `mpc-node` and the API gateway now refuse key generation, raw-digest signing, every legacy signing scheme and any network other than testnet/devnet. The debug-only `dev-unfreeze` feature lifts only the keygen, raw-signing and legacy-scheme refusals for testnet development (a release build with it does not compile); non-test networks are refused in every build. Each refusal has a named `freeze_refuses_*` test.
