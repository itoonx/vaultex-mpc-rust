- **Shipped-build guard (M5 #8).** A new CI job, `Shipped-build guard`, builds `mpc-node` and the API gateway in release exactly as the Docker image ships them (only those two packages, so no workspace feature unification, with `--locked` and a fresh target dir). It fails if any workspace crate in that build has `local-transport` (test parameters), `gg20-simulation`, `dev-unfreeze` or an `experimental` feature enabled. Each run first proves the guard can fire: a canary rebuild with test parameters must be flagged, and both binaries from it must refuse to start.
- Both binaries now refuse to start when a release build links the test parameters. The check runs before any configuration is read; debug builds are unaffected.
