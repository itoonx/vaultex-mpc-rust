- **Boot-node keystore mount removed (M5).** The standalone boot-node wrapper (`scripts/node.sh`, `infra/node/`) no longer offers `init --keys` to bind-mount an existing keystore: a multi-party CLI keystore holds every party's share and must never be given to a single node. Key shares now live only in a fixed docker-managed volume that the node fills by DKG; `up` refuses old state that still records a host mount, and `infra/node/test-node-wrapper.sh` guards against reintroducing it.
