- **Verifier kernel: policy bundle governance follow-ups (ADR-11, 2026-10-17).** While a loosening is pending, any bundle that would supersede it, including an emergency tightening, now needs M-of-N admin signatures, so no single admin can cancel a pending change such as an admin-set rotation (freezing stays 1-of-N). A bundle's version may now be up to 16 above the highest version a signer has accepted (provisional), instead of exactly one above. The parent-digest link still fixes the order, so a signer that never received a loosening cancelled elsewhere can install the cancelling bundle directly and ends in the same state as the others, while a bundle built on a history the signer does not have is refused. The 30-day cap on the loosening time lock is now an owner decision. The policy vector file is regenerated (regression vectors from the kernel's own encoder; the independent oracle has not reproduced them yet).
