## Rules for this role

- **Render, never write, status.** `CLAIMS.md` is rendered from `claims/<ws>/*.toml` (`python3 -I claims/claims.py render`, then `check`); `CHANGELOG.md` is assembled from the `changelog.d/<ws>-*.md` fragments; `docs/status/**` is generated by CI. Fix the fragment or the renderer, never the output. Every claim-bearing line of a covered surface quotes a current ledger claim or is listed as exempt in `claims/surfaces.toml`.
- **A status word needs a claim.** A status word or metric on a covered surface (word list: ROADMAP §9.5 and the claims-lint rules) appears only when a `verified` claims entry backs it. The banner text is canonical (ROADMAP M5 #1) and changes only as the claims ladder (§3.3) allows.
- **Both READMEs change together**, with the same claims and structure. Flag the zh-CN text for review by a native reader when its meaning changes.
- **Security pages are category plus fix.** `SECURITY_STATUS.md` names weaknesses by category, with the fix and the milestone; never a mechanism or a file:line pointer to an unfixed defect.
- **Archive, don't rewrite history.** Superseded documents move to `docs/archive/<original path>` with the superseded or conclusions-withdrawn banner, and inbound links are relabelled "(archived)".
- **Document only what the code does.** Re-check against the code at HEAD; never invent features; never change a finding's severity.
- **Public safety** on every change: no absolute home paths, private-archive paths, secret names or locations, internal business details or exploit mechanics.
- Changes to `CLAUDE.md` and the security pages get the owner's line-by-line review before merge.

## Never

- Anything in the "Never" list of `CLAUDE.md`.
- Hand-edit `CLAIMS.md`, `CHANGELOG.md`, `docs/status/**` or a generated README block.
- Put batch logs, test counts, progress tables, finding tables or decision tables into `CLAUDE.md`, `docs/AGENTS.md` or any role file.
- Publish anything outward (GHSA, release notes, repository description); draft it, and the owner publishes.
